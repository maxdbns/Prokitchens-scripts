# Comparatif Complet : Lusha vs ZoomInfo

## ⚠️ DISCLAIMER IMPORTANT

Ce document est basé sur mes connaissances à jour jusqu'à mai 2025. **Les prix et certaines features peuvent avoir changé**. Pour les données critiques :
- **Pricing** : demander devis auprès des vendeurs (ZoomInfo en particulier ne publie jamais ses prix)
- **Features** : vérifier directement dans les dernières démos produit
- **Couverture data France** : tester avec un POC avant engagement

---

## 1. VUE D'ENSEMBLE

### LUSHA
- **Fondée** : 2015 (Israël)
- **Type** : Plateforme B2B de prospection / Lead intelligence
- **Positionnement** : Accessible, orientée PME/Startups, forte présence US
- **Public cible** : SDRs, sales reps, growth hackers
- **Modèle** : Freemium + abonnement mensuel ou crédits
- **Pays couverts** : 150+ pays (couverture inégale)
- **Taille base data** : ~500M contacts professionnels estimés

### ZOOMINFO
- **Fondée** : 2007 (US)
- **Type** : Plateforme d'intelligence commerciale / Sales intelligence
- **Positionnement** : Enterprise, premium, très complet
- **Public cible** : Teams sales complètes (SDRs, AEs, managers), marketing
- **Modèle** : Abonnement annuel, devis commercial uniquement
- **Pays couverts** : 200+ pays (excellente couverture US/CA/UK)
- **Taille base data** : ~750M contacts + org charts professionnels

## 3. PRICING

### LUSHA

| Plan | Prix (USD/mois) | Crédits annuels | Utilisateurs | Features |
|------|-----------------|-----------------|--------------|----------|
| **Free** | 0 | 50 | 1 | Recherche basique, 50 contacts/mois |
| **Starter** | ~50-100 | 1000 | 1-3 | Recherche avancée, bulk enrichment |
| **Pro** | ~150-300 | 3000-5000 | 3-5 | Toutes features, intégrations CRM |
| **Enterprise** | Sur devis | Custom | Illimité | Custom, support dédié |

**Notes pricing Lusha:**
- Modèle hybride : **abonnement mensuel + crédits par action** (recherche, enrichissement, contact téléchargé)
- Engagement annuel = réduction ~20%
- Essai gratuit limité
- Engagement minimum généralement ~$100/mois
- Tarif indicatif total TCO annuel : 1 200 - 3 600 USD pour une petite équipe

### ZOOMINFO

| Plan | Prix (USD/an) | Utilisateurs | Focus |
|------|---------------|--------------|-------|
| **Sales Executive** | ~6 000 - 12 000 | 1-2 | Individual contributor |
| **Sales Manager** | ~18 000 - 30 000 | 3-5 | Team management + analytics |
| **Enterprise** | 50 000+ | 10+ | Full platform + custom |

**Notes pricing ZoomInfo:**
- **Aucun prix public** — tout en devis commercial
- Facturation annuelle obligatoire
- Modèle : utilisateurs nommés (named seats)
- Engagements minimums généralement 1-3 ans
- Coûts additionnels possibles : modules add-on (intent, technographics, etc.)
- TCO annuel typique pour petit équipe : 20 000 - 40 000 USD minimum
- Les modules d'intent data et technographics ajoutent ~20-40% au coût

**⚠️ Différence clé** : Lusha est pay-as-you-go (flexible), ZoomInfo est seats + commitment (coûteux mais "illimité" en usage)

## 7. API & INTÉGRATIONS TECHNIQUES

### LUSHA API

```
Endpoints principaux :
- GET /search → rechercher contacts
- GET /contacts/{id} → détail contact
- POST /enrich → enrichir liste de contacts
- GET /profile/{linkedinURL} → enrichissment via LinkedIn URL
- POST /bulk → upload CSV pour enrichissement
```

**Rate limits** :
- Plan-dépendant
- Typiquement 100-1000 requests/jour

**Format** :
- REST JSON
- Webhooks (optionnel)
- Authentification : API key

**Documentation** : Medium/claire

### ZOOMINFO API

```
Endpoints principaux :
- POST /search → recherche avec 200+ critères
- GET /company/{id} → données entreprise complètes
- GET /contact/{id} → données contact complet
- POST /search_companies → recherche firmes
- POST /search_contacts → recherche contacts
- Webhooks → alertes real-time (intent, job changes, etc.)
```

**Rate limits** :
- Basés sur le plan (high pour Enterprise)
- Généralement 50-500 requests/minute

**Format** :
- REST JSON
- Webhooks robustes
- Batch processing possible
- Authentification : OAuth 2.0 + API key

**Documentation** : Très complète

**Avantage ZoomInfo** : API plus riche, plus stable, meilleur support technique

## 12. QUESTIONS CLÉS À POSER AUX VENDEURS

### Questions Communes

1. **Démo & Trial**
   - Période d'essai gratuit ? Combien de jours ? Avec quel scope ?
   - POC possible ? Coût ? Durée ?

2. **Pricing & Engagement**
   - Prix exact pour notre use case (1-3 utilisateurs, France-focused)
   - Engagement minimum ? Durée contrats ? Pénalités résiliation ?
   - Modules optionnels : coûts additionnels ?
   - Tarif volume si on scale ?

3. **Data & Couverture**
   - Taux de couverture exact France ? (% contacts disponibles)
   - Taux de validité email ? (dernière mesure)
   - Taux de rebond ? (hard bounce %)
   - Fraîcheur données ? Update frequency ?
   - Comment gère les changements de poste ?

4. **Données de notre secteur**
   - Référence client restaurant/QSR/traiteur ? (pour valider pertinence)
   - Exemple de lead list sur notre segment NAF (56.10C, 56.21Z, etc.)
   - Couverture PME/TPE vs Enterprise ?

5. **Intégrations**
   - Intégration Salesforce/HubSpot : niveau de profondeur ? Sync bi-directionnel ?
   - Lead routing automatique disponible ?
   - Webhooks & real-time sync ?
   - Custom fields mapping ?

6. **Support & SLA**
   - Response time SLA ?
   - Onboarding process ? Durée típique ?
   - Dedicated CSM ?
   - Training fourni ?

7. **Compliance & Data**
   - DPA signé pour RGPD ?
   - Comment gérés les opt-outs ?
   - Où hébergées les données ?
   - Droits d'oubli : process ?

### Questions Lusha-Spécifiques

8. **Modèle crédit**
   - Comment comptabilisé les recherches ? (credit cost par recherche)
   - Cost de l'enrichissement batch ?
   - Rollover des crédits non utilisés ?
   - Alertes quand crédit faible ?

9. **Chrome extension**
   - Fonctionne bien sur toutes versions LinkedIn ?
   - Peut exporter les recherches en liste ?
   - Historique des recherches gardé ?

### Questions ZoomInfo-Spécifiques

8. **Intent data**
   - Quelles sources de l'intent ? (clarifier proprietary signals)
   - Accuracy de l'intent scoring ? (dernières metrics)
   - Latency entre signal et notification ? (real-time ?)
   - Peut customiser les signaux follow ?

9. **Org charts**
   - Accuracy % sur France spécifiquement
   - Frequency update org charts
   - Hierachie complète vs partielle ?
