PARTIE 1 : LUSHA - RÉSUMÉ COMPLET
================================================================================

IDENTITÉ ET POSITIONNEMENT
--------------------------
Lusha est une plateforme israélienne fondée en 2015 spécialisée dans la
prospection B2B et l'enrichissement de données de contact. Elle est positionnée
comme une solution accessible, particulièrement adaptée aux petites équipes de
ventes, startups, et growth professionals. Le modèle commercial est flexible
avec abonnement + paiement à l'usage (crédits).

ARCHITECTURE GÉNÉRALE
---------------------
Lusha opère à partir d'une base données combinée de :
- Scraping de LinkedIn et sites carrière
- APIs publiques
- Partenaires B2B
- Feedback utilisateurs

La plateforme fournit une recherche décente (pas excellente) avec filtrage par
fonction, secteur, taille entreprise, localisation. L'interface est simple et
le Chrome extension est pratique pour sourcer directement sur LinkedIn. Environ
500M+ contacts professionnels stockés.

DONNÉES DISPONIBLES - CONTACTS
------------------------------
Pour chaque contact trouvé ou enrichi, Lusha fournit :
- Prénom, nom, fonction (job title)
- Email professionnel (avec validation/bounce checking)
- Téléphone mobile (disponibilité 40-60% selon région)
- Lien LinkedIn
- Entreprise actuelle
- Secteur d'activité (NAF/SICS)
- Localisation (ville, pays, région)
- Historique changements de poste (derniers 5 ans)

DONNÉES DISPONIBLES - ENTREPRISES
---------------------------------
Pour chaque entreprise, Lusha fournit :
- Nom légal et DBA
- Secteur d'activité (SICS)
- Taille (nombre de salariés estimé)
- Localisation (siège)
- Site web
- Secteur principal
- Nombre total d'employés contactables

DONNÉES NON DISPONIBLES / LIMITATIONS
------------------------------------
- Aucune donnée financière (CA, résultat net, bilan)
- Pas d'org charts (hiérarchie entreprise)
- Pas de signaux d'intent (web activity, événements, etc.)
- SIREN/SIRET français non disponibles
- Scoring leads très basique
- Pas d'intelligence sur concurrents
- Pas de tracking levées de fonds

RECHERCHE ET FILTRAGE
--------------------
Lusha propose une interface de recherche avec filtres avancés :
- Fonction (job title) : libre texte + suggestions
- Secteur : multiple choices (SICS)
- Taille entreprise : seuils définies
- Localisation : pays/région/ville multi-select
- Revenu annuel estimé : fourchettes
- Technologie utilisée : Lusha scan les technos (G2 stack detect)
- Employés récemment changé de poste
- Emails validés seulement
- Boolean search pour recherches complexes

ENRICHISSEMENT BATCH
-------------------
Vous pouvez télécharger une liste CSV de contacts (juste noms + entreprises)
et Lusha enrichit la liste avec emails, téléphones, et données entreprise.
Chaque enrichissement = crédits consommés.

CHROME EXTENSION
----------------
L'extension Lusha sur LinkedIn est populaire auprès des SDRs. Elle permet de :
- Voir l'email d'une personne vue sur LinkedIn (inline)
- Enrichir un profil LinkedIn avec un clic
- Construire une liste de prospects directement dans LinkedIn
- Exporter en une liste dans Lusha (sauvegarde automatique)
- Fonction recherche directe dans LinkedIn People

SCORING LEADS
-------------
Lusha fournit un score de lead basique (0-100) basé sur :
- Engagement sur la plateforme Lusha
- Readiness (est-ce qu'il/elle change de poste ?)
- Activité récente
Ce scoring est très basique comparé à ZoomInfo.

INTÉGRATIONS CRM
----------------
Lusha s'intègre avec :
- Salesforce : sync 2-way (contacts, opportunités)
- HubSpot : sync leads vers HubSpot
- Pipedrive, Freshsales, Close : intégrations basiques
- Slack : notifications de changements de poste
- Gmail / Outlook : extension email
- Zapier, Make : n'importe quel tool via webhook
- API REST native

-------------------------------
États-Unis : ⭐⭐⭐⭐⭐ (Force majeure)

- De-duplication

Limitation majeure : données de France moins fraîches que US, maintenance
moins fréquente sur segments non-prioritaires.

Rate limits : dépend du plan (typiquement 100-1000 req/jour)
Format : REST JSON, Webhooks optionnels
Authentification : API key
Documentation : Medium, acceptable

PARTIE 2 : ZOOMINFO - RÉSUMÉ COMPLET
================================================================================

IDENTITÉ ET POSITIONNEMENT
--------------------------
ZoomInfo est une plateforme américaine fondée en 2007 (merger ZoomInfo +
Datanyze en 2019). Elle est positionnée comme la plateforme premium B2B
d'intelligence commerciale / sales intelligence. Elle cible les équipes sales
complètes (SDRs + AEs + managers) et offre une vision 360° du paysage
commercial. Modèle commercial : abonnement annuel, devis uniquement.

ARCHITECTURE GÉNÉRALE
---------------------
ZoomInfo opère à partir d'une base de données massive combinant :
- Proprietary web traffic data (1000+ sources)
- Intent signals (recherches, contenus visités, etc.)
- Dépôts brevets, transactions M&A, levées de fonds
- APIs publiques
- Partenaires technologiques
- Corrections utilisateurs

La plateforme fournit une recherche très avancée avec 200+ critères de filtrage.
Environ 750M+ contacts professionnels + org charts complets stockés. Base
données mise à jour quotidiennement pour signaux critiques.

DONNÉES DISPONIBLES - CONTACTS
------------------------------
Pour chaque contact, ZoomInfo fournit :
- Toutes les données Lusha (prénom, nom, email, téléphone, fonction, LinkedIn)
- PLUS :
  - Email primaire validé + email secondaire/ancien si disponible
  - Téléphone bureau + mobile validés
  - Informations relatives (reporting manager, directs reports)
  - Historique carrière complet (5+ employeurs précédents)
  - Score engagement personnalisé par contact
  - Job change alerts (real-time)
  - Mobile device type si tracked
  - Social profiles (Twitter, etc.)

DONNÉES DISPONIBLES - ENTREPRISES
---------------------------------
Pour chaque entreprise, ZoomInfo fournit :
- Toutes données Lusha PLUS :
  - Org chart COMPLET : structure hiérarchique, reporting lines
  - DONNÉES FINANCIÈRES :
    * Chiffre d'affaires (CA)
    * Résultat net
    * Croissance YoY (%)
    * Autres ratios financiers
  - Signaux d'intent :
    * Recherches web (keywords trouvés intéressants)
    * Participation salons/événements
    * Dépôts brevets
    * Levées de fonds
    * M&A transactions
    * Recrutements massifs
  - Competitors identifiés
  - Tech stack utilisé (Technographics)
  - Partenaires technologiques
  - Événements importants (CEO change, IPO, etc.)
  - Board members et executive team nommés

DONNÉES NON DISPONIBLES / LIMITATIONS
------------------------------------
- Pas de génération de contenu (mails, etc.)
- Pas d'automatisation marketing avancée
- Couverture France/Europe moins bonne que US
- SIREN/SIRET français non disponibles nativement
- Org charts France peu fiables (data quality issue)
- Intent data sourced from 3rd parties (transparence variable)

RECHERCHE ET FILTRAGE
--------------------
ZoomInfo propose 200+ critères de recherche :
- Fonction (job title) : très granulaire (titre + niveau)
- Secteur : SICS + industries custom
- Taille entreprise : seuils multiples
- Localisation : pays/état/ville/code postal
- Revenus : précis par tranche
- Employees : nombre précis
- Croissance : YoY %
- Technos utilisées : 1000+ technos identifiables
- Intent signals : lesquels cherchez ?
- Org chart : niveau hiérarchique (C-suite, VPs, etc.)
- Événements : levées de fonds, M&A, IPO, etc.
- Competitors : exclude/focus
- Job changes : quand changé de poste ?
- Boolean search + saved searches

Résultat recherche : enrichi de scores intent + signaux automatiques.

SCORING LEADS
-------------
ZoomInfo fournit un scoring prédictif très avancé :
- Predictive scoring : ML-basé, quelle est proba de convertir ce lead ?
- Intent scoring : à quel point ce lead montre-t-il de l'intérêt ?
- Engagement scoring : activité récente
- Personnel score : individual vs account-level
- Recommandations : "next best action"

Ce scoring est 10x plus sophistiqué que Lusha.
